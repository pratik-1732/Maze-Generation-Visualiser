
# 🧩 Maze Visualizer

An interactive web app to visualize maze generation algorithms with dynamic animations and customizable controls.

## 🌟 Features

- Visualizes maze generation using:
  - Depth-First Search (DFS)
  - Randomized Prim’s Algorithm
  - Kruskal’s Algorithm
- Smooth animations with `anime.js`
- Adjustable grid size and algorithm selection
- Responsive and interactive UI
